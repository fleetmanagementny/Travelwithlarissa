# Travel With Larissa
Coming-soon landing page for travelwithlarissa.com.

## Publish
1. Create a public GitHub repository named `travelwithlarissa`.
2. Upload `index.html` and `background.png` to the repository root.
3. Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, **main**, **/(root)**, and save.
4. Once the GitHub Pages URL works, set the custom domain to `travelwithlarissa.com` in Pages settings.
5. At your domain registrar, configure GitHub Pages apex A records: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`; add `www` CNAME pointing to your GitHub Pages host (`YOURUSERNAME.github.io`).
6. After DNS propagates, enable **Enforce HTTPS** in Pages settings.
